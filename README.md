# המרתף בתלת־ממד

מודל תלת־ממדי של יחידת המרתף, לפי התכנית של המעצבת. אפשר להסתובב בו, להיכנס לנקודות מבט (מהספה, מהמיטה, מהכניסה, חדר הרחצה) ולהשוות אפשרויות: ארון, מטבחון, מיקום הטלוויזיה, מסגרת הוויטרינה, דלת חדר הרחצה, גובה ראש הגשם, צבעי ריפוד ותאורה.

ב**מצב חיים** איתי ומיה גרים ביחידה: בוחרים להם מה לעשות (לישון, להתקלח, לעבוד בשולחן, לראות טלוויזיה, קפה, לקרוא בכורסה...) או לוחצים על החפץ במודל, והם הולכים לשם ועושים את זה. סרגל השעה למעלה מזיז את אור היום, ובערב המנורות נדלקות לבד.

## איך פותחים

- לחיצה כפולה על `index.html` פותחת אותו בדפדפן. צריך חיבור לאינטרנט.
- ב-VS Code אפשר גם להריץ בטרמינל `python3 -m http.server 8000` ולפתוח את http://localhost:8000

## עבודה עם Claude Code ב-VS Code

1. פותחים ב-VS Code את התיקייה `The BASEment` (File → Open Folder).
2. פותחים את Claude Code (האייקון בצד או בפקודה `claude` בטרמינל).
3. Claude Code קורא לבד את הקובץ `CLAUDE.md`, ושם כתוב לו הכל: איך הקבצים בנויים, מערכת הקואורדינטות, המידות מהתכנית ומה כבר הוחלט.
4. מבקשים בעברית, למשל:
   - "תוסיף מראה מעל הכיור בחדר הרחצה"
   - "תשנה את הספה לספה פינתית"
   - "תעשה את ברז הכיור בברונזה"
   - "תעדכן ב-CLAUDE.md שבחרנו מטבחון של 200"

## מה יש בתיקייה

- `index.html` — העמוד
- `css/styles.css` — העיצוב של הלוח והעמוד
- `js/` — המודל עצמו, מחולק לפי נושא: חדר, ריהוט, חדר רחצה, תאורה, טלוויזיה, ממשק, ומצב החיים (הדמויות `people.js`, ההליכה `nav.js`, הפעולות והשעון `sim.js`, הלוח `simui.js`)
- `CLAUDE.md` — ההוראות ל-Claude Code
- קובץ ה-PDF של המעצבת — המקור לכל המידות. הוא לא עולה ל-GitHub (מוגדר ב-`.gitignore`)

## פרסום ב-GitHub Pages

מעלים את התיקייה למאגר ציבורי ב-GitHub, ואז ב-Settings → Pages בוחרים Deploy from a branch, ענף `main`, תיקייה `/ (root)`. כל Push מעדכן את האתר תוך דקה-שתיים.
